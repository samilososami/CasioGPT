# CasioGPT v0.1.0

Primera release independiente del cliente CasioGPT para Casio fx-CG50.

## Incluye

- `CASIOGPT.g3a`: interfaz de chat nativa de 384×216.
- Streaming incremental de respuestas mediante el firmware de `cg50-espmod`.
- Verificación de API key, ESP32, Wi-Fi e Internet.
- Cancelación con F6, escritura durante la respuesta y salida limpia.
- `casiogpt_api.example.txt`: plantilla sin credenciales.
- `checksums.txt`: SHA-256 verificable de los binarios publicados.

## Requisito importante

Esta release contiene el add-in. Para la conexión necesita una XIAO ESP32-C3
con el firmware compatible y CasioWIFI del proyecto
[`cg50-espmod`](https://github.com/samilososami/cg50-espmod/releases/latest).

La API key no forma parte de ningún artefacto. Crea `casiogpt_api.txt` en la
raíz de la calculadora y coloca dentro únicamente tu clave de Ollama Cloud.

Probado físicamente en una Casio fx-CG50. CasioGPT es un proyecto independiente
y no oficial.
