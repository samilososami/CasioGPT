# CasioGPT v0.1.1

Release de fiabilidad para el arranque de CasioGPT.

## Cambios

- Hasta diez intentos automáticos para detectar la ESP32, recuperar Wi-Fi,
  comprobar HTTPS e iniciar la sesión del chat.
- Reapertura de UART entre intentos y progreso visible `N/10`.
- Recuperación automática de una red guardada cuando el enlace cae durante la
  comprobación de Internet.
- Errores definitivos y legibles después de agotar los intentos; la interfaz no
  queda bloqueada.
- Pruebas de host que fuerzan éxito en el décimo intento y agotamiento completo.

## Artefactos

- `CASIOGPT.g3a`
- `casiogpt_api.example.txt`
- `checksums.txt`

Requiere el firmware **cg50-espmod v0.1.2 o posterior** para aprovechar la
recuperación completa y el progreso de la comprobación HTTPS. La API key no
forma parte de ningún artefacto.
